

# ManosCerca: Conectando Cuidado, Sembrando Tranquilidad 🤝👵

**ManosCerca** es una plataforma web intuitiva, segura y accesible que revoluciona la forma en que las familias encuentran **cuidadores cualificados** para personas mayores. Desarrollado como **Proyecto Final** del programa de **Desarrollo de Aplicaciones Web** en el IES Trassierra, esta solución tecnológica responde a la creciente demanda social de cuidado de calidad para una población envejecida, basándose en la **confianza, la calidad y la accesibilidad**.

## 💡 Propósito del Proyecto

En un contexto de aumento de la longevidad, encontrar un cuidador de confianza y cualificado puede ser un desafío. ManosCerca nace para cerrar esta brecha, ofreciendo un punto de encuentro digital donde:

* **Las familias** pueden buscar y conectar con cuidadores que se ajustan precisamente a sus necesidades.
* **Los cuidadores** pueden gestionar sus perfiles profesionales y acceder a oportunidades laborales relevantes.

### 🎯 Características Principales

| Funcionalidad | Descripción |
| :--- | :--- |
| **Registro y Perfiles Detallados** | Creación de cuentas específicas para familias y cuidadores con información completa y relevante. |
| **Búsqueda Personalizada** | Filtros avanzados para que las familias encuentren cuidadores basados en requisitos específicos (horario, especialidad, ubicación). |
| **Mensajería Segura** | Un sistema interno de comunicación para coordinar y generar confianza antes de la contratación. |
| **Valoraciones y Reseñas** | Sistema de *rating* para asegurar la calidad y transparencia del servicio. |
| **Accesibilidad** | Diseño enfocado en la usabilidad, incluyendo consideraciones para personas con discapacidades. |

## 🛠️ Tecnologías Utilizadas

El proyecto fue desarrollado utilizando un *stack* **moderno, robusto y escalable**, siguiendo una arquitectura de *Full Stack Development*.

### Frontend (SPA - Single Page Application)

Construido con el framework progresivo Vue.js para ofrecer una experiencia de usuario dinámica y fluida.

| Tecnología | Descripción |
| :--- | :--- |
| **Vue 2** | Framework de JavaScript para la construcción de interfaces de usuario. |
| **Vue Router** | Gestión de rutas para navegación en la SPA. |
| **Bootstrap / Bootstrap-Vue** | Framework CSS para un diseño responsivo y consistente. |
| **Element UI** | Librería de componentes UI para una interfaz elegante. |
| **Axios y Vue-Axios** | Cliente HTTP para la comunicación con el Backend. |
| **Vuelidate** | Validación de formularios robusta y declarativa. |
| **Sass** | Preprocesador CSS para una hoja de estilos mantenible. |

### Backend (API RESTful)

Implementado con el entorno de ejecución Node.js para un rendimiento rápido y eficiente.

| Tecnología | Descripción |
| :--- | :--- |
| **Node.js y Express.js** | Entorno de ejecución y framework web para construir la API. |
| **MySQL** | Sistema de gestión de bases de datos relacional para la persistencia de datos. |
| **jsonwebtoken (JWT)** | Autenticación y autorización segura. |
| **argon2** | Algoritmo de *hashing* de contraseñas de alta seguridad. |
| **Multer** | Middleware para la gestión de subida de archivos (ej. fotos de perfil). |
| **Nodemailer** | Servicio para el envío de correos electrónicos (ej. recuperación de contraseña). |

## 🚀 Proceso de Desarrollo

El proyecto siguió un ciclo de desarrollo riguroso que incluyó:

1.  **Análisis de Necesidades:** Investigación de la demanda social y requisitos funcionales.
2.  **Diseño del Sistema:** Definición de la arquitectura, *mockups* y base de datos.
3.  **Implementación:** Desarrollo del Frontend y Backend con énfasis en seguridad y usabilidad.
4.  **Gestión y *Deployment*:** Utilización de Trello para la organización de tareas y priorización.

### 🛣️ Próximas Mejoras (Roadmap)

* Implementación de **filtros de búsqueda avanzados** basados en geolocalización.
* Sistema de **verificación de antecedentes** (KYC) para cuidadores.
* **Selección de idioma** (Internacionalización).
* **Optimización del rendimiento** y escalabilidad de la base de datos.
